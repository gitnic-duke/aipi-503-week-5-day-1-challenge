# Week 5 Day 1 - Weather report app

This challenge allows a user to obtain weather information for the city they input

## Instructions for running:
1. Copy your API key from OpenWeather.
If you don't have one, create one after signing up on https://openweathermap.org/
2. Create a .env file with the content OPENWEATHER_API_KEY={your_API_key}
3. Save the file

Run:
```bash
python3 main.py
